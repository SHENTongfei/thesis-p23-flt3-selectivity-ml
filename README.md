# 面向急性髓系白血病的 FLT3 骨髓增殖激酶靶向性机器学习精确判定

> 针对 FLT3-ITD 突变在急性髓系白血病中的预后意义，建立靶向性精确判定模型，支撑白血病精准分型。

## 一、方法

- **模型**：GatedGraphConv 门控循环图卷积（GRU 消息传递）

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：2500 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
